# Rubric: 01-01 — Где JavaScript нашёл свойство

## Invariants

- [ ] Во всех трёх вопросах выбран корректный результат выполнения кода.
- [ ] Каждое объяснение прослеживает конкретные объекты в порядке поиска и
  останавливается в том месте, которое следует из входного фрагмента.
- [ ] Наличие ключа, собственное владение и прочитанное значение не смешаны в
  один признак.
- [ ] Присваивание и `delete` во втором вопросе объяснены через состояние объекта
  до следующего чтения, без выдуманной копии всего prototype.

## Valid alternatives

- Термины могут отличаться от текста README, если из объяснения однозначно видно,
  какой объект проверяется первым и почему поиск продолжается либо заканчивается.
- Допустима схема цепочки вместо сплошного текста.

## Evidence and safety

- [ ] `observations.md` содержит прогноз, записанный до запуска, и фактический
  локальный вывод; расхождения разобраны через первый пропущенный объект цепочки.
- [ ] В `observations.md` сохранён фактический вывод `node --version`, который
  подтверждает требуемую ветку Node.js 24.
- [ ] `answers.json` содержит собственные причины, а не только выбранные буквы.
- [ ] `lab.js`, формулировки quiz и входные объекты не изменены.
- [ ] Заявленный вывод команды относится к фактическому локальному запуску, а не
  к ожидаемому примеру из README.

## Optional improvements

- Дополнительный контрпример с `Object.create(null)` полезен, но не блокирует
  PASS.

## NEEDS_WORK

Верните `NEEDS_WORK`, если хотя бы один ответ неверен, причина сводится к
пересказу выбранной строки или `undefined` трактуется как достаточное
доказательство отсутствия свойства.
