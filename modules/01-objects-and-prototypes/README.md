# 01. Объекты и prototype chain

В прикладном коде чтение `profile.name` выглядит как одна элементарная операция.
У обычного объекта, однако, может быть связан следующий объект — его prototype.
Если собственного поля `name` нет, JavaScript проверяет prototype, затем его
prototype и останавливается на найденном свойстве либо на конце цепочки. Эту
последовательность проверок называют поиском по prototype chain.

Найденное свойство тоже бывает разным. Accessor property хранит функции `get`
и/или `set` вместо обычного значения; если задан `get`, чтение вызывает эту
функцию.

Та же механика становится границей безопасности. Представьте, что `source` —
разобранные недоверенные данные с собственным ключом `"__proto__"`, значение
которого — объект `{ isAdmin: true }`; `target` — пустой обычный объект для
результата, а `key` — очередное имя при копировании.
До копирования `target.isAdmin` возвращает `undefined`. В браузерах и в обычной
конфигурации Node.js 24 `target` наследует исторический accessor `__proto__` от
`Object.prototype`. Поэтому операция `target[key] = source[key]` при
`key === "__proto__"` вызывает этот setter и связывает `target` с переданным
объектом вместо создания обычного собственного поля. После этого собственного
поля `isAdmin` у `target` по-прежнему нет, но чтение `target.isAdmin` возвращает
`true` из нового prototype.

Стандарт помечает accessor `Object.prototype.__proto__` как legacy normative
optional: браузеры обязаны его поддерживать, а другие среды выполнения вправе не
предоставлять; Node.js также позволяет его отключить. В финальной карточке глава
сначала проверит эту предпосылку среды, затем воспроизведёт переход и закроет
границу явной политикой разрешённых ключей.

Эта глава раскладывает чтение и изменение свойств на наблюдаемые шаги. Сначала
вы построите трассу поиска свойства, затем через property descriptor измените
правила чтения, записи, перечисления и удаления найденного свойства, вручную
воспроизведёте `new`, сопоставите `class` с prototype chain и завершите главу
диагностикой prototype pollution. Вопрос главы: где именно JavaScript находит
значение и какие гарантии обязан сохранить код, работающий с чужими объектами?
